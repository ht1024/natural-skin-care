# Natural Skin Care SA — by Norma Perry

Spa website for Natural Skin Care of SA (Stone Oak, San Antonio, TX), built with React, Vite, TypeScript, and Tailwind CSS. Appointment requests are stored in Supabase.

## Development

```bash
npm install
npm run dev
```

## Environment

Create a `.env` file with:

```
VITE_SUPABASE_URL=<your supabase url>
VITE_SUPABASE_ANON_KEY=<your supabase anon key>
```

## Build

```bash
npm run build
```
